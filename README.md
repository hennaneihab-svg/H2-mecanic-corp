## Overview

H2 Mechanic Corp needed an automated scheduling system to replace manual booking procedures. The objective was to provide vehicle owners with a direct booking interface while giving workshop managers an administrative view of incoming requests.

---

## Key Features

### 1. Client Booking Workflow
* Selection of mechanical services and maintenance options.
* Dynamic date and time selection to prevent appointment conflicts.
* Form validation capturing vehicle specifications and customer contact details.

### 2. Administration Dashboard
* Centralized view of pending, scheduled, and past reservations.
* Status update controls for workshop technicians.
* Customer record tracking directly linked to service requests.

### 3. Responsive User Interface
* Accessible on mobile, tablet, and desktop devices.
* Fast asset delivery and clean typography suited for an automotive business.

---

## Tech Stack & Architecture

* **Frontend:** HTML5, CSS3 (Responsive Design), Vanilla JavaScript
* **Backend Logic:** Form processing, appointment scheduling logic, and state management
* **Deployment:** Production domain configuration and SSL setup
